# Human Harness 首个参考模板 · 地块土壤污染状况调查

`land-investigation.hh.json` 可以安装到本仓库版本的 Human Harness。启动后打开菜单，选择「导入本地 JSON 模板」，选中该文件并点击「验证并保存模板」。再用「环评 · 地块土壤污染状况调查」创建项目。

| 工作 | 当前模板安排 |
| --- | --- |
| 收集素材 | 受理项目、红线、用途、企业与历史、踏勘访谈；按类别并行提取原值、来源结论和图件登记。 |
| 整理素材 | 经审核的提取结果整理为项目成果。用户确认第一阶段结题或继续采样。继续采样的项目在委托及外部完成均确认后请求现场、检测和质控资料。 |
| 成文与目录 | 完整调查的目录整理与检测结果分析独立推进。小节在所需目录和成果经审核后成文。初步稿覆盖前三章，完整稿覆盖七章、33 个小节和 70 个固定三级、四级标题。企业章节按审核后的实际对象展开。 |
| 审核与组装 | Human 在双 Todo 内审阅小节，程序以固定顺序拼入当前有效版本。修改来源或采用稿后，原下游成果失效。内部稿经审核后可下载 Markdown 或 Word。 |

本版把 P2p（v5.10.71）的 275 项段落计划和 86 个表、图位置投影到任务说明。沿用轮次和条件规则。表格根据已确认的表位和原值填写，图位记录已核对的素材引用，内部核查事项保存在任务结果。Human Harness 的 Word 内审稿包含标题层级、可更新目录、页码以及稿件中的表格。图位保留文字引用。正式 Word/PDF 版式及图片自动嵌入仍由原 P2p 工作台处理。现有 `.eia.zip` 项目继续用 P2p 打开，新模板以新项目为入口。

模板文件只含流程和规则。项目原件、项目结论、人工决定和成果历史由各项目独立保存。旧示例可从 `examples/` 手动导入，已有 Human Harness 项目继续使用创建时的模板快照。

## 项目计划

模板提供资料、Agent、人工审核和机构工期的估时。项目顶部的「项目计划」能分别试算两条路线，调整可用人力与截止日，并锁定甘特图基准。见[项目计划说明](../../docs/project-planning.md)。

## 项目要求

创建项目时先选择需要的外包地测或政府调档事项，填写验收截止日。启动前可预览首批任务与交付项。联系、受理、跟进和回件验收依次进入 Human Todo。见[项目要求与组织分工](../../docs/project-coordination.md)。

## 验收参考

用通用工作台导入模板后，按启动预览准备首批 Human Todo。正式调查路线在资料整理后由负责人确认。第一阶段和完整调查均由已审小节组装，最终稿进入 Human Todo 后验收。在「项目交付」下载选定的文件格式，Word 可在打开后更新目录页码。

本仓库的两条流程以合成材料验收。配置、写作规则和排版参数随模板发布，具体项目的原件与结论保存在项目内。

## 修改模板

`report-profile.json` 保存从 P2p 目录和段落职责投影的通用规则。材料类别和受理条件见 `materials.json`。流程、分析依赖和成文方式见 `build-template.mjs`。

修改后递增模板版本，在本目录运行 `node build-template.mjs` 生成导入文件。运行 `node build-template.mjs --check` 可以检查提交文件是否与定义一致。
