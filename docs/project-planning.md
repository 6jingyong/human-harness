# Human Harness 项目计划

在项目顶部打开「项目计划」，设置开始日、交付目标日、每日可用工时和并行通道。点击甘特图中的任务可以修改估时、设置截止日或调高优先级。保存之前会显示完工日期的变化和被推迟的任务数量。点击「锁定基准」保存各项计划日期，之后的滚动预测与基准并列显示。

排程使用已有项目依赖图。材料提交与验收、Agent 执行、人工审核、机构交接和临时补问分别占用对应通道。Agent 和人工审核各占自己的资源，依赖审核的后续任务要等审核完成。排程使用周一至周五的工作时段，从项目时区 09:00 起按配置分配。人工完成记录提供完成点，Agent 运行记录提供实际开始和结束时间。

项目目标日和任务截止日均按当地自然日结束。双 Todo 顶部会提示当日需要处理、已经逾期或预计影响交付的可行动工作，并显示估计需要的人力、机构确认或 Agent 重试。点击提示直接进入原任务。调高优先级会改变同资源可开始事项的顺序，关联的前置工作也会优先。保存后参与真实的 Agent 自动派发优先级排序；勾选工时窗口可限制 Agent 自动启动时段，已开始的运行可继续。Agent 并行数取项目执行策略，所有项目共享的进程并发上限在运行时另外生效。

## 环评排程

模板 0.2.0 预置资料整理、分节写作、人工审核和机构检测的工时估算。可在计划页分别试算第一阶段结题和继续采样。路线假设只进入排程，材料 Todo 和工作启动继续按实际人工决定与外部里程碑触发。选择采样时，检测报告、现场记录和质控资料仍要排在机构完成之后。

### 推进次序

1. 实现通用时限、有限工时、甘特图、基准和工作台提醒。用环评两条路线以及通用文档模板验证。
2. 用真实环评项目校准三类用时，尤其是资料受理、逐节审批和机构实际等待。分清材料尚未产生、用户尚未投入及任务在运行三种延误。
3. 扩充可用时段到人员和日期，支持组内共享容量、停工日与实际预约。扩展到工作台之外的提醒渠道时单独配置接收方式。

当前版本在打开的工作台显示提醒，机构工期和人工工时均为估算。资源按单个项目内可互换的通道管理。实际用时、共享排程和其他提醒渠道各自需要后续接入。
